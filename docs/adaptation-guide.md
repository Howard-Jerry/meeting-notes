# 公开版适配说明

本版从既有会议整理工作流提取通用文字处理方法。生成入口为 scripts/publish.sh，传入上游文件路径；不在包内记录维护者的私人路径。

保留：来源与版本区分、讨论确定程度、待办提取、责任及日期缺口、原文定位、后续明确修正、按用户格式输出、保存与执行状态区分。

移除：机构专用技能路由、私人历史记录入口、内部工作流依据、HTML模板及配套资源。写作复核改为本包内的直接规则，不要求安装其他技能。

新增：四份完全虚构的输入、前三例主会话输出、第四例新上下文AI输出、公开使用说明和本地完整性检查。上游原件没有被覆盖，公开包也不安装到维护者的日常技能目录。

更新时先核上游是否仍适用。结构或替换锚点变化时生成脚本会中止；由维护者审查后更新适配，不默默猜测。生成后复核脱敏扫描和相关行为案例。自动扫描只能发现列明模式，不能代替逐文件检查或授权核对。
