# 虚构示例四：第一次独立试用

以下所有人物与活动均为虚构。会议：纸艺社体验活动筹备；日期未记录。

[1] 主持人：先按30个名额准备，成员甲明天把报名链接发出去。
[2] 成员乙：我建议先收20元材料费。不过这只是建议，我还没有算成本。
[3] 主持人：这次免费，收费建议不采纳。
[4] 成员丙：场地还没确认。我来问场地，下周三反馈能容纳多少人。
[5] 主持人：修正刚才的安排：先按12个名额准备。成员甲暂停发报名链接，等成员丙反馈后再定开放日期。物料由谁准备还没定。
[6] 成员甲：知道了。我明天先把报名页文案整理成草稿给大家看，不发链接。
[7] 主持人：好，成员甲整理草稿。场地确认后是否能增加名额再讨论。
